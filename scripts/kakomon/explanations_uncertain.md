# 解説の未確認メモ

`src/infrastructure/data/explanations/` の解説を作成したときに、根拠を確認できなかった肢の記録。
問題データの正誤は本試験の正解から確定した値で、ここに挙げた肢でも正誤そのものには問題がない。未確認なのは解説の理由づけや、根拠とした判例・先例の内容である。

- 解説を修正する際や、専門家に確認を依頼する際の手がかりとして残している。
- 根拠を確認できたら、解説を直したうえで該当行を削除する。
